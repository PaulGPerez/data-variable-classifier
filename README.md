# Variable Classifier 

Dealing with variable classifications can be annoying to remember and implement. I built this interactive script as a friendly reminder to double-check your data types and plan the best visualizations before analysis.

### What it Does
Instead of guessing which chart to use, this script asks you simple `1` or `2` questions to classify your variable as Numerical or Categorical. Based on your answer, it automatically generates and displays the correct categorization and visual recommendation to plot (ex histogram) using Python.
